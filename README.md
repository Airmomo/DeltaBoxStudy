# DeltaBoxStudy · 三角洲鼠鼠导航 1.3.0 学习项目

**原作者：南神（抖音：南神（三角洲行动））**

DeltaBoxStudy 是南神提供的开源学习项目，用于学习 DeltaBox 1.3.0 的叠加层界面、点位数据结构与前端交互实现。
项目包含 HTML、CSS、JavaScript、代码注释和本地素材，并提供可独立运行的浏览器演示。
通过本地地图瓦片和模拟定位，可以观察分类筛选、坐标投影、关联路线与详情卡片的工作方式。

界面与数据代码位于 `renderer/`，浏览器演示位于 `study/`，运行与校验工具位于 `tools/`。

## 快速开始

安装 Node.js 18 或以上版本，进入本目录后运行：

```bash
npm start
```

打开 **http://127.0.0.1:43130**。项目没有第三方 npm 依赖，无需先执行 `npm install`。
服务器仅监听本机，按 `Ctrl+C` 停止。

首页提供作者、赞助和源码入口；点击「打开地图演示」进入 HUD 界面。

- 左侧切换地图、模式、分类、性质、事件及潮汐监狱楼层；默认显示保险箱分类。
- 「显示全部分类」/「清空分类」用于快速观察点位，也可以逐项勾选分类。
- 地图空白处拖动平移，滚轮缩放，「适配地图」恢复全图视野。
- 双击可见物资点查看详情卡；悬停可观察关联路线和区域。
- 「暂停模拟定位」隐藏点位，点击「继续模拟定位」恢复。
- 浏览器页面获得焦点时，`M` 切换模拟定位、`Esc` 暂停、`Ctrl+Shift+H` 折叠/展开侧栏；这些只在当前页面内处理，不注册系统热键。
- 重要收集、阿萨拉记牌器、关于页及浏览器本地状态保存可供学习。清除本机演示状态可在浏览器开发者工具中清空此站点的 Local Storage。

需要更换端口时，例如 PowerShell：

```powershell
$env:PORT = '43131'
npm start
```

应通过上述 HTTP 服务打开演示，直接双击 HTML 文件的 `file://` 方式不支持页面的本地 JSON 请求。

## 项目内容

| 内容 | 文件/目录 | 可以学习的实现 |
| --- | --- | --- |
| 界面与逻辑 | `renderer/overlay.html` | HUD 布局与缩放、地图/模式切换、分类分槽记忆、筛选、点位/地标投影、路线、区域、详情、鼠标命中、定位代次与过期观察拒绝 |
| 桥接脚本 | `renderer/bridge.js` | 宿主消息、请求应答、存储快照和事件回调协议 |
| 点位数据库 | `renderer/data/data.js` | 六图 `Points`/`Labels`、类别、模式、说明、坐标、子点与关联结构 |
| 配置与样式 | `renderer/data/` | 潮汐楼层、地图配置、样式、分类名、同步清单与关于示例数据 |
| 图片素材 | `renderer/images/` | 地图缩略图与瓦片、分类图标、收集品、卡牌、赞助二维码 |
| 第三方许可文本 | `renderer/licenses/` | 第三方许可与来源说明 |
| 学习演示 | `study/` | 浏览器桥替身、模拟定位、瓦片展示、平移、缩放、双击命中与项目首页 |
| 辅助工具 | `tools/`、`tests/` | 零依赖本机服务、文件 SHA-256 校验与服务边界测试 |

`renderer/` 共有 **2,768 个文件**，总大小 **8,513,732 字节**。
其中有 **2,746 个图片文件**、**12 个数据/配置文件**、**8 个许可证文件**，以及 `overlay.html` 与 `bridge.js`。

## 学习建议

1. 从 `overlay.html` 的 `state`、`persist`、`stashModeCats` 和 `applyModeCats` 理解 UI 状态与地图/难度分槽。
2. 阅读 `pointVisible`、`floorMatch`、`buildCategoryNodes`、`syncCategoryNodes`，观察筛选、子点、路线与节点复用。
3. 阅读 `acceptTracking`、`applyView` 和 `markerAt`，理解世界坐标到屏幕坐标、固定屏幕图标尺寸及命中判断。
4. 阅读 `showPopover` 和卡片构建函数，理解名称/性质、说明、素材和单张详情的生命周期。
5. 对照 `renderer/bridge.js` 与 `study/bridge.js`，理解桥接接口、事件订阅与浏览器模拟实现。

界面逻辑主要集中在 `overlay.html` 的内联脚本内，可以结合注释阅读；浏览器演示层通过独立脚本提供模拟定位与地图操作。

## 文件校验与测试

`archive-manifest.json` 记录 `renderer/` 中每个文件的相对路径、字节数和 SHA-256，可用于检查文件完整性。

校验命令：

```bash
npm run verify
npm test
```

`verify` 会核对全部 2,768 个基线文件，报告文件丢失、改动或新增，并检查版本、南神作者标识、六图及点位记录总数。
学习时建议在 `study/` 中添加实验代码，保留 `renderer/` 基线便于对照与校验。

## 项目范围与演示边界

本项目提供界面、数据结构和前端交互的学习实现。浏览器演示使用本地资源和模拟定位消息，不采集游戏、不注册系统热键，也不连接线上更新或授权服务。

部分详情引用的图片和视频未包含在本项目中；可以阅读正文及素材引用处理代码，对应图示可能无法显示。
「直播/录屏模式」等需要宿主支持的控件用于展示界面，不执行系统操作。
浏览器模拟定位用于学习投影与交互，不具备真实游戏识别、点位穿透或自动换图功能。
